# Summary

On **November 1, 2023**, the Forum of Incident Response and Security Teams (FIRST) officially released the **Common Vulnerability Scoring System (CVSS) Version 4.0**[^first-cvss-v4-0].

# Significance
- Introduced separate scoring nomenclature: CVSS-B (Base), CVSS-BT (Base + Threat), CVSS-BE (Base + Environmental), and CVSS-BTE.
- Modernized impact metrics with dedicated Safety (`S`) and Automatable (`AU`) vectors.
