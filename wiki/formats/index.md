# Formats

Machine-readable advisory, VEX and discovery formats.

## Structure

- [CSAF 2.0](csaf/index.md): OASIS Common Security Advisory Framework: document structure, profiles, distribution, aggregators, provider metadata.
- [VEX](vex/index.md): Vulnerability Exploitability eXchange: OpenVEX, CSAF VEX profile, CycloneDX VEX, status vocabulary, minimum requirements.
- [security.txt](security-txt/index.md): RFC 9116 fields, placement and lifecycle.
