# CSAF 2.0

OASIS Common Security Advisory Framework: document structure, profiles, distribution, aggregators, provider metadata.

## Concepts

- [CSAF Base Profile](csaf-base.md) — Baseline document architecture and foundation profile of the Common Security Advisory Framework (CSAF) Version 2.0, establishing core metadata, tracking, publisher, and product tree requirements.
- [CSAF Informational Advisory Profile](csaf-informational-advisory.md) — Specialized CSAF 2.0 profile for publishing non-remediation security notices, defensive hardening guidelines, end-of-life warnings, and architecture advisories.
- [CSAF Security Advisory Profile](csaf-security-advisory.md) — Specialized vendor advisory profile under CSAF 2.0 detailing fixed vulnerabilities, affected and patched product versions, remediation actions, and CVSS severity metrics.
- [CSAF Security Incident Response Profile](csaf-security-incident-response.md) — Specialized CSAF 2.0 profile designed for CSIRTs and PSIRTs to issue early warnings, situational updates, and active exploitation advisories during ongoing cybersecurity incidents.
- [CSAF Vulnerability Exploitability eXchange (VEX) Profile](csaf-vex.md) — Specialized machine-readable profile under CSAF 2.0 asserting actual exploitability status (known_not_affected, known_affected, fixed, under_investigation) to eliminate SBOM false positives.
