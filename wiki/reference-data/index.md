# Reference data

Scoring, prioritisation and identification systems used in disclosure.

## Structure

- [CVSS](cvss/index.md): CVSS v4.0 and v3.1 metric groups, vectors, qualitative severity, environmental and supplemental metrics.
- [EPSS](epss/index.md): Exploit Prediction Scoring System model, scores and percentiles.
- [SSVC](ssvc/index.md): Stakeholder-Specific Vulnerability Categorization decision trees and outcomes.
- [CWE](cwe/index.md): Common Weakness Enumeration views and its use in CVE Records.
- [Identifiers](identifiers/index.md): CPE, package URL, SWID and other product identifiers used to name affected products.
