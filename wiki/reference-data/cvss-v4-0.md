# Summary

**Common Vulnerability Scoring System (CVSS) v4.0** in coordinated vulnerability disclosure and remediation prioritization[^first-cvss-v4].

Next-generation standard introducing CVSS-B, CVSS-BT, CVSS-BE, and CVSS-BTE scores with expanded threat and environmental granularity.

Provides standardized objective scoring and prioritisation metrics to guide patching urgency.
