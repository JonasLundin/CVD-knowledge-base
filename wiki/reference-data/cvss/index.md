# CVSS

CVSS v4.0 and v3.1 metric groups, vectors, qualitative severity, environmental and supplemental metrics.

## Concepts

- [Common Vulnerability Scoring System (CVSS) v3.1](cvss-v3-1.md) — Quantitative severity scoring specification evaluating base, temporal, and environmental metric groups to assess software vulnerability characteristics.
- [Common Vulnerability Scoring System (CVSS) v4.0](cvss-v4-0.md) — Next-generation vulnerability scoring standard introducing CVSS-B, CVSS-BT, CVSS-BE, and CVSS-BTE nomenclatures, separate Vulnerable/Subsequent system impacts, and Attack Requirements.
