# Summary

The **FIRST PSIRT Services Framework** provides a reference capability model for establishing, structuring, and operating an enterprise Product Security Incident Response Team (PSIRT)[^iso-iec-29147].

# Service Areas
1. **Core Services**: Vulnerability discovery, intake, triage, remediation coordination, and advisory publishing.
2. **Ecosystem Engagement**: Peer coordination, standardisation participation, and security researcher community relations.
