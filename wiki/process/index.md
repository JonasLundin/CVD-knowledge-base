# Process

The disclosure lifecycle: intake channels, triage, embargo and coordination including multi-party coordination, advisory publication and updates, safe-harbour terms, bug bounty interfaces, PSIRT operations.

## Concepts

- [Process: Advisory Publication and Patch Release](advisory-publication.md) — Simultaneous public release of security advisory, CVE Record, and software patch or remediation guidance.
- [Process: Embargo Management and Coordination](embargo-management.md) — Establishing mutually agreed embargo windows (typically 90 days) during remediation development.
- [Process: Intake Channels and Security.txt](intake-and-reporting.md) — Establishing discoverable intake mechanisms (RFC 9116 security.txt, PGP keys, web forms) for vulnerability submission.
- [Process: Multi-Party Vulnerability Coordination](multi-party-coordination.md) — Procedures for managing vulnerabilities impacting shared libraries, protocols, or multi-vendor hardware components.
- [Process: Triage, Reproduction, and Impact Assessment](triage-and-validation.md) — Initial verification of vulnerability reports, root cause analysis, severity assessment, and reproducibility confirmation.
