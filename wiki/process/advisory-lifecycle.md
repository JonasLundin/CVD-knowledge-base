# Summary

The **Security Advisory Lifecycle** outlines the stages through which public security advisories are authored, approved, distributed, and subsequently maintained[^oasis-csaf-2-0].

# Lifecycle Stages
1. **Drafting**: Documenting vulnerability overview, impacted versions, workarounds, and fixes in CSAF 2.0.
2. **Internal Approval**: Executive, legal, and product sign-off.
3. **Public Release**: Coordinated publication alongside software update distribution.
4. **Revision & Updates**: Incrementing document tracking versions when additional affected versions or new exploit intelligence emerge.
